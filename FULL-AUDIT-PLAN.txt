2026년 급여 실수령액 계산기 전체 검사 계획
=========================================

목적과 범위
-----------
이 문서는 현재 구현된 급여 실수령액 계산기와 연봉 역산 기능을 체계적으로 검사하기 위한 실행 기준이다.
금액은 1원 단위로 가능한 값이 매우 많으므로 모든 금액을 하나씩 시험하지 않는다. 대신 유한한 입력값은 전체 조합을 확인하고, 금액은 최소·최대·법정 경계·세액표 구간 경계와 경계 전후를 검사한다. 계산 기대값은 공식 자료, 이미 대조한 공식 간이세액표 또는 독립적인 수학적 조건으로 정한다.

검사 전제
---------
- 현재 화면에는 적용월 선택과 원천징수 비율 입력이 없다. 적용월은 Asia/Seoul 기준 당월이며 원천징수 비율은 100%로 고정된다.
- 매니페스트에 등록된 계산 기준은 2026년이다. 미등록 연도의 결과를 만들거나 다른 연도 기준으로 대신 계산하지 않아야 한다.
- 고급 보험료 직접입력은 기능 설정 기본값이 OFF다. 현재 사용자 화면의 기본 동작은 자동 산정이다.
- 실제 급여명세서와의 일치는 사업장별 신고 보수·비과세 항목·정산에 좌우되므로 별도 자료 검증이다.

검사 항목 및 기대 결과
----------------------

A. 기본 기능 및 화면 입력 흐름
1. 월급 입력: 양의 정수 월급여를 입력해 계산한다. 결과의 월 총급여는 입력액과 같고, 공제합계는 표시된 6개 공제 항목 합계와 같으며, 실수령액은 총급여-공제합계다.
2. 연봉 입력(퇴직금 별도): 연봉을 12로 나눈 몫을 월 급여로 사용한다. 나머지 1원 미만 금액은 버리고 화면 요약에도 동일한 월 환산액을 표시한다.
3. 연봉 입력(퇴직금 포함): 연봉을 13으로 나눈 몫을 월 급여로 사용한다. 나머지는 버린다.
4. 급여 유형 전환: 연봉에서 월급으로 바꾸면 기존 입력 연봉을 현재 퇴직금 선택에 맞춰 12 또는 13으로 나눈 값이 입력되고, 자동 환산 안내가 표시된다. 이후 사용자가 금액을 직접 입력하면 환산 안내는 사라지고 한글 금액 읽기가 갱신된다.
5. 계산 기능 전환: 월 실수령액과 연봉 역산 간 입력 영역·버튼·결과 요약이 각 기능에 맞게 보이고, 숨겨진 입력값은 현재 계산에 섞이지 않는다.
6. 결과 상세: 상세내역은 최초 접힘, 열고 닫을 때 aria-expanded 값과 표시 상태가 일치한다. 공제 항목 합계와 계산 기준 보조내역이 결과와 일치한다.

B. 월 실수령액 입력 경계
7. 급여액: 0, 음수, 소수, 비숫자, 빈 값은 계산을 막고 오류를 표시한다. 1원 및 유효한 양의 정수는 계산 가능해야 한다(비과세액은 급여액보다 클 수 없음).
8. 연봉 환산 경계: 1원, 11원, 12원, 13원, 12·13의 배수 및 배수 바로 전후를 검사한다. 월 환산은 선택한 나눗수의 내림 결과와 일치해야 한다. 0원 월급으로 환산되는 연봉은 거부한다.
9. 비과세액: 0원과 총급여액과 같은 값은 허용, 총급여액보다 1원 큰 값·음수·소수·빈 값은 거부한다. 0원 과세급여의 공제·세액 처리는 공식 규칙과 현재 추정 모델에 맞는지 확인한다.
10. 공제대상가족: 1명 및 11명 허용, 0명·12명·소수·빈 값 거부.
11. 8~20세 자녀: 0명, 공제대상가족과 같은 수 허용. 가족 수보다 1명 많은 값·음수·소수 거부. 1명·2명·3명에서 자녀 공제액이 공식 기준에 맞는지 확인.
12. 원천징수: 화면에 선택/입력 기능이 없고 제출 값이 100%인지 확인한다. 회사 적용 비율 차이는 안내에 남아야 한다.

C. 급여 계산 산식 및 법정 경계
13. 국민연금 기준소득월액: 2026년 1~6월 하한 400,000원·상한 6,370,000원, 7~12월 하한 410,000원·상한 6,590,000원 각각 경계 직전/경계/직후를 검사한다. 1,000원 미만 소득 끝수 처리와 보험료 10원 미만 처리를 확인한다.
14. 건강보험·장기요양보험: 2026 요율과 보수월액 보험료 하한·상한, 가입자 부담 및 장기요양 산식을 공식 자료의 근거와 대조한다. 경계에서 보험료가 급격히 역전되거나 상한을 벗어나지 않아야 한다.
15. 고용보험·소득세·지방소득세: 근로자 요율, 간이세액표 적용, 자녀 공제 시점, 10원 단위 처리와 합산 결과를 공식 근거 또는 기존 승인된 기대값과 비교한다.
16. 세액표 구간 전체: 646개 급여 구간의 시작점과 끝 직전 및 11개 공제대상가족 열을 계산 함수에 통과시킨다. 각 구간에서 반환된 기본 세액이 공식 XLSX 값과 모두 일치해야 한다. 현재 XLSX·JS·공식 XLSX의 7,106개 셀 데이터 대조는 완료됐지만, 계산 함수의 전체 구간 경계 통과는 별도 검사한다.
17. 1천만 원 초과: 공식 표 상단 초과 계산식의 각 구간 경계 직전/경계/직후와 11개 가족 수를 검사한다. 계산 결과는 유한한 값이며 구간 전환에서 산식 오류가 없어야 한다.
18. 적용 시점: 2026년 2월/3월 자녀 공제 전환, 6월/7월 국민연금 상·하한 변경을 검사한다. 월 선택 UI가 없으므로 이 검사는 내부 날짜별 규칙 검증이다.

D. 연봉 역산
19. 목표 실수령액: 빈 값, 0원, 음수, 소수 거부. 유효 목표에서는 계산 결과 월 실수령액이 목표액 이상이어야 하고, 역산된 월 총급여보다 1원 낮은 급여로는 목표에 미달해야 한다(최소 급여 조건).
20. 역산 연봉 표시: 최소 월 총급여를 12개월 연봉으로 환산하며 연봉 역산 화면은 퇴직금 포함 선택을 요구하지 않는다. 비과세액·가족 수·자녀 수 입력 조건이 역산과 표시 결과에 일관되게 반영되어야 한다.
21. 범위 상한: 내부 월 총급여 상한 1,000,000,000원에서 목표 달성 여부를 검사한다. 상한으로 달성 불가능한 목표는 오류 안내를 내고 오래된 결과를 숨겨야 한다.

E. 고급 보험료 직접입력
22. 설정 OFF: UI가 숨겨지고, 직접입력 값이 전달되더라도 기본 자동 계산 결과와 같아야 한다.
23. 설정 ON: 국민연금/건강보험 각각 자동·직접 모드를 확인한다. 한 보험의 수동 입력은 그 보험료 산정에만 영향을 주고 나머지 항목은 자동 기준 결과를 유지해야 한다.
24. 입력 허용 범위: 국민연금은 적용 기간별 하한/상한과 경계 밖 값, 건강보험은 0~1,000,000,000원과 경계 밖 값, 소수/빈 값/잘못된 모드를 검사한다. 유효 범위 밖 값은 계산을 막고 설명을 표시해야 한다.

F. 오류·데이터·반응형 동작
25. 검증 실패 뒤 재계산: 오류 발생 시 이전 계산 결과가 새 입력의 결과처럼 남지 않아야 하며, 값을 고친 뒤 다시 계산하면 새 결과를 표시해야 한다.
26. 데이터 로딩: 성공, 미등록 기준, 파일 로딩 실패, 실패 후 재시도, 중복 요청 순서에서 현재 요청에 맞는 데이터만 결과를 갱신해야 한다.
27. 반응형: 320px, 375px 및 데스크톱에서 월 실수령액/연봉 역산/상세내역을 확인한다. 문서 가로폭은 화면 폭을 넘지 않아야 한다. 자동 테스트는 실제 스마트폰 검증을 대체하지 않는다.
28. 접근성·입력 보조: 금액 숫자 키패드, 빈 입력 처리, 한글 금액 읽기 실시간 갱신, 상세 토글의 접근성 상태 및 모션 감소 설정을 확인한다.

기존 테스트와 추가 예정 작업
---------------------------
- 기존 Node 테스트: 대표 계산 결과, 일부 입력 오류, 2026년 적용월 경계, 세액표 데이터 형태, 상한, Config ON/OFF와 일부 고급 입력, 비동기 로딩·재시도, CSS/HTML 계약을 확인한다.
- 기존 Playwright 테스트: 기본 계산과 공제내역, 연봉 환산, 금액 읽기, 연봉 역산, 일부 오류 및 320px/375px 가로 넘침을 확인한다.
- 추가 검사 우선순위: (1) 세액표 646개 구간 계산 함수 경계와 11개 가족 수 전체 통과 (2) 수치 경계 전후와 입력 검증의 체계적 케이스 (3) 역산 최소값의 1원 전후 증명 (4) 결과 무효화·재시도/오래된 비동기 요청 (5) 고급 입력 ON일 때 실제 브라우저 UI. 기존 테스트를 먼저 실행해 기준선을 기록한 뒤 추가한다.
- 화면의 실제 한국 당월 결정과 고정 100%는 브라우저에서 계약 테스트를 추가한다. 내부 함수가 다른 withholding 인수를 허용하는 단위 테스트는 이 사용자 기능 확인을 대신하지 않는다.

검사 결과 판정 및 한계
----------------------
- 항목별로 실행 명령/브라우저, 통과·실패·미실행, 기대 결과 출처, 수정 및 재검사 결과를 기록한다.
- 공식 간이세액표 데이터 전수 대조 완료는 유지하되, 계산 함수의 전체 급여 구간 통과 여부는 별도 판정한다.
- 보험료율·일부 산식의 공식 대조와 자동 회귀검사는 실제 급여명세서 일치 보증이나 급여 실무 전문가 검토를 뜻하지 않는다.
- 보험별 비과세 보수의 법정 정의 차이로 현재 단일 비과세 입력 모델과 실제 급여명세서가 다를 수 있다. 이 모델 제한은 별도 결과로 명시한다.
- 실제 휴대전화, Vercel Preview, 실급여명세서 비교는 별도 실행 및 접근이 필요한 항목으로 자동 테스트 완료와 구분한다.
