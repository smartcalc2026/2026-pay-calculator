- 가족 수 1~11명, 각 가족 수에서 가능한 자녀 수, 2026년 1~12월 조합 924개를 검사했습니다. 입력 허용 여부, 자녀 공제 적용 시점, 실수령액 합계를 확인했습니다.
- 1천만원 초과 누진 구간, 국민연금의 상·하한/1천원 단위 경계, 건강보험 하한·상한과 장기요양·고용보험 산식, 입력 오류, 역산 결과의 1원 최소 조건을 검사했습니다.
- Playwright에 한국 기준 당월 자동 적용 및 원천징수 100% 고정, 입력 변경 시 이전 결과 숨김, 설정 ON 고급 국민연금 입력의 기간별 상한 검증, 늦게 도착한 오래된 계산 결과 무시 검사를 추가했습니다.

판정 및 범위 제한
- 추가한 자동 검사에서 계산기 본체의 수정이 필요한 오류는 발견되지 않았습니다. 이번 변경은 전수검사 자동화와 문서 반영이며, 급여 계산 코드와 사용자 화면은 수정하지 않았습니다.
- 최초 Playwright 실행은 기본 샌드박스의 로컬 소켓 제한으로 테스트 서버를 열지 못했습니다. 프로젝트 전용 로컬 서버를 허용한 실행에서는 15개 모두 통과했습니다.
- 이 검사는 2026년 등록 규칙과 선택한 경계·조합을 자동 확인한 결과입니다. 모든 가능한 원 단위 급여값, 모든 법률 예외, 실제 회사 급여명세서 일치 여부를 의미하지 않습니다.
- 실제 iOS/Android 기기, Vercel Preview/Production, 급여 실무 전문가 검토, 실제 급여명세서 표본 비교는 미실행입니다. 비과세 항목별 보험 산정 차이는 현재 단일 비과세 입력 모델의 제한으로 남습니다.
- 공식 간이세액표 7,106개 데이터 셀 대조 및 공식 기준 검토 내역은 앞선 2026-11-05 항목을 참조하세요.
