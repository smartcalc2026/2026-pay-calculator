2026년 대한민국 급여 실수령액 계산기
====================================

1. 계산기 목적
--------------
2026년 월 총급여, 비과세액, 공제대상가족 수, 8~20세 자녀 수, 원천징수 비율을 입력해 예상 월 실수령액과 공제 항목별 금액을 계산하는 정적 웹 계산기입니다.

급여 입력값은 브라우저에서 JavaScript로만 계산합니다. 이 프로젝트에는 급여 정보를 서버로 전송하거나 저장하는 기능이 없습니다.

2. 2026년 적용기준
------------------
- 근로소득 간이세액표: 첨부된 2026.03.01 기준 XLSX 조견표 데이터를 2026년 1~12월에 동일하게 사용합니다. 표 구간을 임의로 보간하지 않습니다.
- 자녀 공제: 계산기 설정에 따라 2026년 3월부터 별도 반영합니다. 1~2월은 동일한 기본 간이세액표 세액을 사용하되 별도 자녀 공제는 적용하지 않습니다.
- 국민연금 근로자 부담률: 4.75%로 설정되어 있습니다. 기준소득월액 하한·상한은 2026년 1~6월 400,000~6,370,000원, 2026년 7~12월 410,000~6,590,000원으로 월별 적용합니다.
- 건강보험, 장기요양보험, 고용보험 및 지방소득세: 설정 파일의 2026년 요율과 끝수 처리 기준을 적용합니다.
- 간이세액표 기본 세액은 공제대상가족 수 1~11명 열을 사용합니다. 1,000만원 초과 급여는 원본 별표의 초과 구간 산식을 적용합니다.
- 비과세액은 입력한 총급여에서 차감한 과세 대상 급여를 기준으로 계산합니다.

이 계산기는 추정치입니다. 실제 공제액은 회사의 신고 보수월액, 보수 구성, 정산, 상여, 보험료 조정 등으로 달라질 수 있습니다.

5. 업데이트 방법
----------------
1) 변경된 연도별 공식 기준과 시행일을 공식 기관 자료 및 법령에서 확인합니다.
2) 간이세액표가 바뀌면 공식 원본 표의 구간·가족 수 열을 검증하고 data/income-tax-YYYY.js에 정확히 반영합니다. 구간 사이를 보간하거나 미확인 값을 추정하지 않습니다.
3) 보험료율·상하한·끝수 처리·시행일은 data/payroll-rules-YYYY.js에서 관리합니다.
4) salary/calculator.js의 계산 흐름을 바꿔야 할 때는 변경 근거와 함께 수정하고, tests/test-calculator.js의 기준값도 공식 원본으로 재검증합니다.
5) 프로젝트 루트에서 Node.js가 설치된 환경에서 다음 명령으로 회귀 테스트를 실행합니다:
   cd tests
   node test-calculator.js
6) 테스트가 통과한 뒤 정적 호스팅에 프로젝트 폴더 내용을 배포합니다. 도메인을 사용하는 경우 배포 전에 salary/index.html의 SEO canonical/OG URL을 실제 공개 URL로 설정하세요.

6. 2027년 기준 변경 시 수정할 파일
---------------------------------
- data/payroll-rules-2026.js: 연도, 보험료율, 국민연금 상·하한 적용 기간, 자녀 공제 시행일 등 연도별 설정을 갱신합니다. 2027년용으로 파일명을 바꾸면 salary/index.html의 script 경로와 salary/calculator.js의 설정 참조도 함께 갱신해야 합니다.
- data/income-tax-2026.js: 2027년 공식 근로소득 간이세액표 전체 데이터 및 1,000만원 초과 산식으로 교체합니다. 시행일이 다른 표가 있으면 월별 적용 로직도 검토합니다.
- salary/calculator.js: 연도 검증, 적용월, 시행일 분기, 2027년 표 구조가 바뀐 경우 계산 로직을 수정합니다.
- salary/index.html 및 index.html: 제목, 설명, 기본 적용월, 안내 문구와 스크립트 경로를 2027년 기준으로 갱신합니다.
- tests/test-calculator.js: 공식 원본을 기준으로 대표값·경계값·시행일 테스트를 갱신합니다.
- README.txt: 기준 연도, 출처, 업데이트 내역을 갱신합니다.
